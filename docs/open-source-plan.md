# Luna Translator 开源计划

更新日期：2026-10-28

目标仓库：[VUILabsHub/Luna-Translator](https://github.com/VUILabsHub/Luna-Translator)

当前阶段：先发布项目介绍与开源计划，随后按里程碑整理应用源码。本文描述规划，不表示相应功能已在本仓库交付或完成验证。

## 1. 项目目标

提供一个开发者能够独立启动、修改和扩展的实时语音翻译 Web 应用。首版优先公开 Web 前端、后端、必要共享包和模型服务适配器，通过外部服务完成实际的语音识别、同传和语义向量计算。

Android 与 iOS 在后续里程碑处理，不作为首版发布条件。

## 2. 开源边界

| 范围 | 处理方式 |
| --- | --- |
| Web 前端 | 优先整理浏览器音频输入、原文与译文字幕、翻译语音播放及相关交互 |
| 后端 | 整理网关、会话管理、音频转发、产品 API 及必要存储能力 |
| 共享代码 | 保留 Web 与后端协作所需的协议、状态和文本/音频处理代码 |
| 模型接入 | 提供接口契约、适配器、配置说明和调用示例，允许替换外部服务 |
| 历史、回放、分享、账号 | 梳理依赖后确定首版支持清单及独立配置方式 |
| 会议与 RTC 扩展 | 核实依赖后作为可选组件，说明额外服务需求 |
| Android / iOS | 后续整理配置、构建文档与实机验收 |
| 模型与内部模型推理服务 | 不包含 ASR、同传、Embedding 对齐等模型的权重、训练代码、训练数据和内部推理服务实现 |
| 内部部署与业务资料 | 不发布凭据、生产配置、签名材料、真实用户数据、内部日志或内部发布记录 |

按允许清单整理社区版本，并保留必要的版权、作者归属和第三方声明。

## 3. 推荐服务与接入方式

| 能力 | 推荐方案 | 计划交付 |
| --- | --- | --- |
| ASR 实时识别 | 百炼 `qwen3-asr-flash-realtime` | 服务端适配、模型/地域配置、音频与事件说明 |
| Embedding 语义向量 | 百炼 `text-embedding-v4` | 向量接口适配、可公开的应用侧对齐流程示例及效果验证 |
| 同传 | [Luna 同传服务](https://simultrans.lunlabs.ai) | 核实后的 API、鉴权、音频格式和试用指引 |
| 其他服务 | 开发者自行配置 | 扩展接口、能力声明与适配器示例 |

官方参考：[百炼实时语音识别](https://help.aliyun.com/zh/model-studio/real-time-speech-recognition-user-guide)、[百炼文本向量 API](https://docs.bailian.console.aliyun.com/en/model-studio/text-embedding-synchronous-api)。模型可用性与接入参数以服务商当前文档和账号开通情况为准。

接入原则：

- 模型名称、服务地址、地域和能力可配置；长期凭据保留在后端。
- ASR、Embedding 和同传按功能组合，不要求每次会话同时调用三项。可复用同传服务提供的原文转写。
- Embedding 生成向量，不等于完整的对齐服务。需要处理分段、匹配和阈值，并验证跨语言效果与延迟。
- Luna 同传服务的 API、鉴权与试用流程仍待核实，不预设未确认的接口路径或调用权限。
- 无凭据时提供明确标注的模拟流程，便于界面开发与自动化检查；真实服务验证单独记录。
- 账号开通、费用、额度、数据处理与使用条件按各服务要求说明。

## 5. 首版验收条件

- [ ] 全新克隆能够按文档启动 Web 与后端，无需内部网络、私有镜像或移动端工具链。
- [ ] 模拟流程有明确标识，未配置能力与外部服务错误有清晰提示。
- [ ] 自行配置外部服务后完成至少一条真实同传链路。
- [ ] 推荐的 ASR、Embedding 和同传接入分别有验证记录；未通过项明确列出，不标为已支持。
- [ ] 首版承诺的历史、回放、分享等功能分别验收。
- [ ] 验证麦克风权限、音频播放、响应式布局、连接失败提示和浏览器错误，并记录耳机或回声控制条件。
- [ ] 长期密钥不进入前端产物；音频/文本的传输、持久化和清理行为有说明。
- [ ] 许可及第三方声明完整，公开内容检查完成，不包含内部模型资产、生产资料或真实用户数据。
- [ ] 普通 PR 的 CI 可独立执行，且不会触发内部部署。
- [ ] 构建、模拟交互、真实服务调用与版本发布的验证结果分别记录。
