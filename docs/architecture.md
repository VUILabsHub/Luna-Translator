# 社区版架构与数据

浏览器 → 同源 Nginx → Go 社区后端 → 用户配置的 Luna / 百炼服务。

- `web/`：整理自产品 Web，保留字幕、设备选择、音频播放、历史与分享界面。
- `packages/core/`、`packages/ui-shared/`：Web 需要的共享协议、音频和文本状态逻辑。
- `backend/core/`、`backend/providers/`：应用层接口及云服务客户端；不运行或加载模型权重。
- `backend/community/`：首版 Web 实际使用的独立接口、单工作区鉴权、一次性会话票据、文件持久化、模型编排。
- `compose.yaml`：Web 和后端两个服务，后端不向宿主机暴露端口，数据卷 `workspace-data` 持久化。

社区后端实现首版产品接口；评测、标注、内部集群发布和移动端后台逻辑不在发行范围。必要共享前端代码仍有兼容类型及后续能力代码，这些能力不会注册为社区后端接口。

## 数据与权限

首次启动生成随机工作区密码与签名密钥，权限为 0600，保存在数据卷。可用私有 `ADMIN_PASSWORD`（至少 12 字符）覆盖密码。登录凭证有效期 12 小时；本地退出清除浏览器会话，已签发令牌到期前仍有效。

历史 JSON 与归档输入/输出 WAV 保存在数据卷。会话票据仅保存在内存中，30 秒有效、一次使用，重启后不保留。没有模型密钥时默认模拟模式，仅产生示例结果和提示音；真实模式会把输入音频发送给所配置的模型提供方。

分享使用随机不可预测 token、最多 30 天有效。只公开所选择记录的快照、字幕和音频，过滤设备信息、配置与追踪信息。撤销持久化到磁盘；删除原记录撤销其所有链接，清理无其他记录引用的音频。已经取得的分享内容无法从访问者设备上收回。

正常停止会保存历史。浏览器意外退出时，上游连接会关闭，未保存为历史的音频可能保留在卷中；维护者可在停服后清理孤立目录。备份整个数据卷可保留密码、签名密钥、历史、分享和音频。

默认不启用产品遥测，也不连接公司数据库、内部模型服务、私有镜像或运营系统。

社区 v0.1 的单人字幕按整段、双向字幕按每轮发言展示，避免把独立 ASR 和译音的不同分句误配。Embedding 适配接口可独立调用与扩展，不能推断出已验证的逐句边界。
