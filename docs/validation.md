## 真实外部服务

使用维护者私有配置与合成测试语音，不发布密钥、账号工作空间、测试音频或原始日志。默认 CI 跳过真实模型测试，不消耗社区模型额度。

- Luna 公共 API：中译英、英译中，收到真实译文及 PCM 译音。
- 百炼 ASR：中文与英文输入均收到非空原文。
- 百炼 `text-embedding-v4`：真实向量与相似度评分通过；这是整段近似配对，未验收逐句精确语义对齐。
- 社区后端完整链路：鉴权 → 实时输入 → ASR/译文/译音 → 归档 WAV → 历史 → 分享 → 公开音频读取；两个方向均通过。
- 完成顺序回归：翻译结束早于 ASR 时，必须等 ASR、音频和归档完成后才向浏览器结束会话，避免丢末句。

可选复测：设置自己的私有环境及 `COMMUNITY_LIVE_TEST=1`、`LUNA_TEST_PCM` 后运行 `go -C backend test ./community -run TestLiveEndToEnd -v -count=1`。输入是单声道 16 kHz PCM16 原始字节；可用 `TEST_SOURCE_LANG=en TEST_TARGET_LANG=zh` 验证反向。仅使用有权提交给服务商的音频。

## 容器与浏览器

本机为 macOS / Apple Silicon，Docker 中运行 Linux arm64；Chrome 实际交互。

- 默认模拟模式：工作区登录、WAV 输入、固定示例字幕、提示音、完成、历史与分享通过；页面持续显示模拟标识。
- 真实模式：合成中文 WAV 完整显示三句原译文，归档原音频 6.10 秒、译音约 5.84 秒，浏览器播放有进度且媒体无错误。
- 分享：创建前告知内容范围；独立页面读取原译文及音频；撤销后原链接显示失效。
- 重建/重启容器后，工作区登录、历史与分享数据仍可读取。
- 麦克风权限未能在该浏览器会话取得可用采集；已检查设备引导。未验证真人麦克风、扬声器回声、耳机路由和跨浏览器长会话；没有向外部模型发送本机麦克风音频。

最终双向交互、手机布局、干净下载和远端 CI 的记录在发布前补齐。

## 发行边界

Apache-2.0 适用于本仓库应用代码；模型、训练数据与内部推理服务不分发。单工作区共享数据，非多租户服务。Windows 脚本尚未在 Windows 实机执行，移动端源码和多人会议不在本版。远程麦克风需要部署者配置有效 HTTPS。真实模型需要自行申请账号与密钥。
