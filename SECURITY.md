# Reporting security issues

Do not post credentials, private recordings or exploit details in public Issues. Use GitHub private vulnerability reporting when available, or contact the repository maintainers through the organization's published contact channel and request a private report destination.

This first release is a single-workspace deployment. Keep the default loopback binding for local use, and place remote deployments behind HTTPS and appropriate access controls. Model service keys are backend-only. Delete/revoke the affected workspace share if content was shared unintentionally.
